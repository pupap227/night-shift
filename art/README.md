# Арт-пайплайн

Игровая логика ссылается на графику **только по asset ID**. Путь вычисляет `Assets` (`code/core/assets.gd`):

    res://art/<kind>/<id>.<png|webp|jpg|svg>   — первый найденный файл побеждает

| kind | Кто использует | ID берётся из | Сейчас |
|---|---|---|---|
| `characters` | карточки, досье, диалоги | `characters.json → portrait` (`doctor_volkov`) | процедурные SVG (`tools/gen_portraits.py`) |
| `icons` | весь UI, метки карты | строки в данных (`"icon": "ambulance"`) | 43 SVG-иконки, белый штрих — цвет задаёт UI |
| `buildings` | `CityBuildings` | `city_map.json → buildings[].id` (`b_er`, `police`) | пусто → здание рисуется процедурно |
| `city`, `events`, `ui` | зарезервировано | — | — |

**Замена ассета:** положите `art/characters/doctor_volkov.png` — он перекроет SVG. Код не меняется.
Портрет: 5:6 (например 1000×1200), голова в верхней половине. Для мелких слотов UI сам делает кроп лица.
Спрайт здания: якорь — нижний центр габарита изометрического основания.
