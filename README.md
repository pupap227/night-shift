# NIGHT SHIFT / НОЧНАЯ СМЕНА — vertical slice

Narrative hospital management. Godot **4.7.2 stable**, 2D, изометрия средствами 2D.
Одна полная ночная смена 22:00–06:00 (~12 мин реального времени на ×1).

## Запуск
Открыть папку в Godot 4.7.2 → F5. Или: `godot --path .`

Управление (тач — основное): тап по карточке → тап по корпусу; или удержание карточки → перетаскивание на корпус/сигнал ·
свайп по ленте — прокрутка · pinch — зум карты · ПКМ/Esc — снять выбор · Пробел — пауза · 1/2/3 — скорость · колесо — зум · перетаскивание карты / WASD — обзор.

## Структура
```
art/        графика по asset ID (см. art/README.md)
audio/      sfx/ + music/ (ambient, tension, crisis — слои по уровню тревоги)
data/       ВСЁ содержимое игры в JSON: персонал, черты, отделения, типы пациентов,
            события, новости города, смена, карта города, аудио-маппинг
code/core/  автозагрузки: Game (состояние+часы+API), Assets, Audio
code/data/  типизированные Resource-классы + DataDB (загрузчик JSON)
code/sim/   StaffMember, PatientCase, EventInstance, Assignment (подбор), EventDirector (эффекты)
code/world/ карта: модель, слои рендера (земля, свет, транспорт, здания, дым, маркеры, дождь), MapView
code/view/  слой представления (visual reset): GameScreen (3 раскладки), HUD, PersonCard, StaffStrip (жесты),
            DragController (тач-drag), SignalBanner/Rail, EventSheet + EventArt, Stamp, Ticker, MenuSheet
code/core/screen.gd  responsive: DPR, safe area (notch / home indicator), режимы portrait / landscape / desktop
code/debug/ автотест-прогон с реальными событиями мыши, sim_test, лист портретов
tools/      генераторы placeholder-портретов и звуков
```

## Архитектура
- **Данные отдельно от логики.** Новый врач / событие / пациент / отделение = правка JSON.
  Эффекты решений — данные (`spawn_patients`, `money`, `alarm`, `flag`, `staff_rest`, `dept_stress`, `schedule_event`…).
- **Единый API действий** в `Game`: `select_staff`, `preview(staff, target)`, `assign`, `resolve_event`.
  `preview` — это «что будет, если…»: его используют подсказка при drag, подсветка карты, диалог и инфо-панель.
- UI и карта только читают состояние и слушают сигналы.
- Сим идёт по игровым минутам; анимации актёров на карте привязаны к игровому времени (пауза/скорость — бесплатно).

## Механики слайса
8 сотрудников с навыками, чертами (модификаторы из данных), усталостью и стрессом (срывы, «без сил») ·
5 отделений + служебные объекты · 3 типа пациентов (+ инцидент охраны) с многостадийным маршрутом
(приёмное → операционная/реанимация/лаборатория) · 10 событий с выбором и таймером решения ·
состояние пациента падает, пока он ждёт · снятие человека с задачи прерывает её (дилемма) ·
3 уровня тревоги (музыкальные слои, тонировка карты) · койки, бюджет, доверие · цели смены · рапорт с сюжетными последствиями.

## Мобильная web-сборка
`tools/build_web.sh` → `build/web/` (Godot Web, nothreads — без требований к cross-origin isolation в Safari).
`.wasm` режется на части <15 МБ и собирается в браузере; `.pck` отдаётся как `.wasm` (для хостов со строгим списком MIME).
Проверка: `tools/test_web.mjs` (Chromium с эмуляцией iPhone, тач).

## Проверка
`godot --path . -- --capture` — сценарный прогон: старт, событие, диалог, клик, drag&drop на карту и на карточку пациента,
команда в операционную, массовое поступление, предупреждение о прерывании, инфо-панель, конец смены. Скриншоты в `user://shots/`.
`godot --headless --path . scenes/debug/sim_test.tscn` — прогон симуляции всей смены без графики.
